# AntaresGateway 5 离线演示

双击 `index.html` 即可在浏览器中打开，无需安装或启动正式服务。

点击“开始演示”可按五步体验选择提供商与模型、配置路由、创建演示密钥、设置预算、运行模拟请求。完成的示例会出现在相关分类列表中；统计数字为独立预设值。

左侧导航可切换主要分类；“全部模块目录”列出从当前软件导航整理出的 94 个入口，可搜索名称并打开各自的虚构示例数据。目录页面使用统一的演示列表，并非正式软件各模块的真实页面或完整操作。列表支持搜索、新增、删除和状态切换；对话体验返回本地预设文本。点击“重置演示数据”可恢复初始示例。

若此前使用过旧版演示并保存了模块数据，点击“重置演示数据”可加载本版的模块专属示例；重置会清除之前手动添加的演示数据。

“功能实验室”提供本地路由回退模拟、示例单价费用计算和文本去重演示；文本清理并不代表实际压缩引擎。各模块列表支持添加、编辑、状态切换和删除演示记录。

流程演示保存的提供商、路由、密钥、预算及请求日志会同步添加到相应分类和模块列表；列表中的独立编辑不会反向更改流程配置。相关模块页面可直接进入流程或功能实验室。

部分模块还提供协议调用、批处理、日志检索、健康检查、事件投递、知识检索、配额计算和消息格式示例。这些操作均在本地生成结果，并非实际服务调用。

全部内容为虚构，操作仅作用于浏览器本地演示数据，不连接上游模型，也不读取或修改正式环境的数据。浏览器若禁用本地存储，更改仅在当前页面有效。

这是独立的交互式概览，不是正式软件完整功能的仿真：模拟列表和对话结果不执行网关、计费、协议、智能体或其他真实服务。不同浏览器或不同打开方式的数据可能相互独立。
